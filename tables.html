Tables & formulas

Use the tables by hand first. The lookup helpers highlight the same row, column, and entry you would find on paper. This course uses the z, t, and χ² tables.

Standard normal tablet tableχ² tableFormula sheet

The standard normal table

The entries give left area P(Z<z), rounded to four decimals. Round z to two decimals. Negative rows use a negative hundredths digit too: row −1.6, column .04 means −1.64.

For z beyond ±3.49, the course treats left area as essentially 0 or 1. For inverse lookups, choose the closest four-decimal entry. Ties use the midpoint z, such as .9500 → 1.645.

The t table

Columns show the upper-tail area α, so the entry is t_{\alpha,\nu}. Use the row df = n − 1 exactly; every df from 1 to 40 is listed, which covers every small-sample problem (n ≤ 40). For a confidence interval use the column α/2; for a test use α (one-sided) or α/2 (two-sided). The last row (∞) gives the z critical values for large samples.

Entries are rounded to three decimals. Software checks use the same df: qt(1 - α, df) in R, scipy.stats.t.ppf(1 - α, df) in Python.

The chi-squared table

Columns show the area to the right α, so the entry is \chi^2_{\alpha,\nu} with P(\chi^2_\nu>\chi^2_{\alpha,\nu})=\alpha. For a 100(1 − α)% interval for σ² with df = n − 1, read the columns α/2 and 1 − α/2. The larger value goes under the lower endpoint.

Entries are rounded to three decimals. Software: qchisq(1 - α, df) in R, scipy.stats.chi2.ppf(1 - α, df) in Python.

The formula sheet

The formulas follow our course conventions. Work each one by hand first.

Center
\bar x=\frac{1}{n}\sum_{i=1}^n x_i \tilde x=\text{middle ordered value}
Spread
s^2=\frac{S_{xx}}{n-1} S_{xx}=\sum (x_i-\bar x)^2=\sum x_i^2-\frac{(\sum x_i)^2}{n} s=\sqrt{s^2}
Quartiles and outliers
IQR=Q_3-Q_1 \text{outlier if } x<Q_1-1.5\,IQR \text{or } x>Q_3+1.5\,IQR
Shifting and scaling
y=x+C:\ \bar y=\bar x+C,\ s_y=s_x y=Cx:\ \bar y=C\bar x,\ s_y=Cs_x
Probability rules
P(A')=1-P(A) P(A\cup B)=P(A)+P(B)-P(A\cap B) P(A)=\frac{N(A)}{N}\text{ (equally likely)}
Conditioning and independence
P(A\mid B)=\frac{P(A\cap B)}{P(B)} P(A\cap B)=P(A\mid B)P(B) \text{independent: }P(A\cap B)=P(A)P(B)
Total probability and Bayes
P(B)=\sum_i P(B\mid A_i)P(A_i) P(A_j\mid B)=\frac{P(B\mid A_j)P(A_j)}{\sum_i P(B\mid A_i)P(A_i)}
Discrete random variables
E(X)=\sum x\,p(x) \text{Var}(X)=E(X^2)-\mu^2 E(aX+b)=aE(X)+b \text{Var}(aX+b)=a^2\text{Var}(X)
Binomial
b(x;n,p)=\binom{n}{x}p^x(1-p)^{n-x} E(X)=np \text{Var}(X)=np(1-p)
Hypergeometric
h(x)=\frac{\binom{M}{x}\binom{N-M}{n-x}}{\binom{N}{n}} E(X)=n\frac{M}{N} \text{Var}(X)=\frac{N-n}{N-1}\,n\frac{M}{N}\left(1-\frac{M}{N}\right)
Negative binomial and Poisson
nb(x)=\binom{x+r-1}{r-1}p^r(1-p)^x E(X)=\frac{r(1-p)}{p} \text{Var}(X)=\frac{r(1-p)}{p^2} p(x;\mu)=\frac{e^{-\mu}\mu^x}{x!} E(X)=\text{Var}(X)=\mu
Continuous random variables
P(a\le X\le b)=\int_a^b f(x)\,dx=F(b)-F(a) E(X)=\int x f(x)\,dx \text{Var}(X)=E(X^2)-\mu^2 F(\eta(p))=p
Uniform and normal
U(A,B):\ f=\frac{1}{B-A} E(X)=\frac{A+B}{2} \text{Var}(X)=\frac{(B-A)^2}{12} z=\frac{x-\mu}{\sigma} x=\mu+z\sigma
Gamma, exponential, chi-squared
\Gamma(n)=(n-1)! \Gamma(\tfrac12)=\sqrt\pi G(\alpha,\beta):\ \alpha\beta,\ \alpha\beta^2 \text{Exp}(\lambda):\ F(x)=1-e^{-\lambda x} \tfrac1\lambda,\ \tfrac1{\lambda^2} \chi^2(\nu):\ \nu,\ 2\nu
Joint distributions
p_X(x)=\sum_y p(x,y) f_X(x)=\int f(x,y)\,dy \text{indep.: }p(x,y)=p_X(x)p_Y(y) E[h(X,Y)]=\sum\sum h\,p
Covariance and correlation
\text{Cov}(X,Y)=E(XY)-\mu_X\mu_Y \rho=\frac{\text{Cov}(X,Y)}{\sigma_X\sigma_Y} \text{Var}(X\pm Y)=\sigma_X^2+\sigma_Y^2\pm2\text{Cov}
Sample mean and CLT
E(\bar X)=\mu \sigma_{\bar X}=\frac{\sigma}{\sqrt n} \bar X\approx N\!\left(\mu,\frac{\sigma^2}{n}\right)\ (n>40) z=\frac{\bar x-\mu}{\sigma/\sqrt n}
Point estimation
\text{Bias}(\hat\theta)=E(\hat\theta)-\theta E(\bar X)=\mu E(S^2)=\sigma^2 E(\hat p)=p
Standard error
\sigma_{\hat\theta}=\sqrt{\text{Var}(\hat\theta)} \sigma_{\bar X}=\frac{\sigma}{\sqrt n} \sigma_{\hat p}=\sqrt{\frac{p(1-p)}{n}}
Moments and likelihood
\frac1n\sum X_i^j=E(X^j) L(\theta)=\prod f(x_i;\theta) \ell'(\hat\theta)=0 \text{Exp: }\hat\lambda=1/\bar x \text{Normal: }\hat\sigma^2=\tfrac1n\sum(x_i-\bar x)^2
Intervals for μ
\bar x\pm z_{\alpha/2}\frac{\sigma}{\sqrt n} \bar x\pm z_{\alpha/2}\frac{s}{\sqrt n}\ (n>40) \bar x\pm t_{\alpha/2,n-1}\frac{s}{\sqrt n}\ (n\le40)
Intervals for p
\hat p\pm z_{\alpha/2}\sqrt{\frac{\hat p(1-\hat p)}{n}} \tilde p=\frac{\hat p+z^2/2n}{1+z^2/n} \tilde p\pm\frac{z\sqrt{\hat p(1-\hat p)/n+z^2/4n^2}}{1+z^2/n}
Bounds and σ²
\mu<\bar x+z_\alpha\frac{s}{\sqrt n} \mu>\bar x-z_\alpha\frac{s}{\sqrt n} \frac{(n-1)s^2}{\chi^2_{\alpha/2,n-1}}<\sigma^2<\frac{(n-1)s^2}{\chi^2_{1-\alpha/2,n-1}}
Test statistics for μ
z=\frac{\bar x-\mu_0}{\sigma/\sqrt n} z=\frac{\bar x-\mu_0}{s/\sqrt n}\ (n>40) t=\frac{\bar x-\mu_0}{s/\sqrt n},\ df=n-1
Test for p; decisions
z=\frac{\hat p-p_0}{\sqrt{p_0(1-p_0)/n}} np_0\ge10,\ n(1-p_0)\ge10 \text{reject }H_0\text{ if p-value}<\alpha
p-values and rejection regions
>:\ P(Z>z),\ z\ge z_\alpha <:\ P(Z<z),\ z\le -z_\alpha \ne:\ 2P(Z>|z|),\ |z|\ge z_{\alpha/2} \alpha=P(\text{Type I}),\ \beta=P(\text{Type II})
