1. Random variables

In Chapter 1 we recorded “variables.” From now on we say random variable, because the value we observe comes from a random experiment or a random sampling process. For a sample space S, a random variable (RV) is a rule that assigns a real number to each outcome in S: a function whose domain is S and whose range is the real numbers.

  • Tell discrete from continuous random variables.
  • Use a PMF, a probability table, and a CDF, including P(a ≤ X ≤ b) = F(b) − F(a−).
  • Compute E(X), E[h(X)], Var(X), and SD by hand, and use the rules for aX + b.
  • Recognize the binomial, hypergeometric, negative binomial, and Poisson settings and compute their probabilities, means, and variances.
  • Approximate a binomial by a Poisson when n > 50 and np < 5.

Notation. Uppercase letters X, Y, Z name random variables, X:S\to\mathbb{R}; lowercase letters are particular values: X(s)=x. For one coin flip, S = {H, T} and X(H) = 1, X(T) = 0, so X counts heads. Other examples: X = student loan debt of a randomly chosen student; Y = 1 for a “yes” answer and 0 for “no.” In a random sample, Y_1,\ldots,Y_n are independent copies of Y.

2. Discrete and continuous random variables

A discrete random variable has possible values that form a finite set or a countably infinite list (a first value, a second value, and so on): the number of defective items in a sample, X ∈ {0, 1, …, 10}; the number of trials until the first success, X ∈ {1, 2, 3, …}. A continuous random variable has possible values that fill an entire interval: the time to failure of a machine, X ∈ (0, ∞); the measurement error of a sensor, X ∈ (−∞, ∞).

3. Probability distributions and the PMF

The probability distribution of X describes how the total probability of 1 is allocated among the possible values of X. For a discrete RV it can be given by a probability mass function, a probability table, or a probability histogram. The probability mass function (PMF) is p(x)=P(X=x), read “the probability that X takes the value x.”

p(x)\ge 0 \sum_{\text{all }x}p(x)=1
Worked example

Coin flips

Flip a fair coin twice (independent flips) and let X count the heads.

x012
P(X = x)1/41/21/4
  1. The four outcomes HH, HT, TH, TT are equally likely; one has 0 heads, two have 1, one has 2.
  2. P(X > 0) = 1/2 + 1/4 = 3/4, or 1 − P(X = 0) = 3/4.
  3. P(X ≤ 2) = 1: every possible value is at most 2.

A Bernoulli random variable takes only the values 0 and 1, with P(X=1)=p and P(X=0)=1-p. One fair coin flip (1 = heads) is Bernoulli with p = 0.5.

4. The cumulative distribution function

The cumulative distribution function (CDF) of a discrete RV gives the probability that X is at most x. It is a step function that jumps by p(x) at each possible value.

F(x)=P(X\le x)=\sum_{y\le x}p(y)
P(a\le X\le b)=F(b)-F(a^-)

Here F(a^-) is the left-hand limit at a; for integer values it is F(a − 1).

Worked example

CDF for two coin flips

  1. F(0) = P(X = 0) = 1/4.
  2. F(1) = 1/4 + 1/2 = 3/4.
  3. F(2) = 1/4 + 1/2 + 1/4 = 1.
  4. So F(x) = 0 for x < 0; 1/4 for 0 ≤ x < 1; 3/4 for 1 ≤ x < 2; and 1 for x ≥ 2.
  5. P(1 ≤ X ≤ 2) = F(2) − F(0) = 1 − 1/4 = 3/4.
Watch out. For a discrete RV, P(X < b) and P(X ≤ b) differ by P(X = b). Translate the words first: “fewer than 11” is X ≤ 10.

5. Expected value

The expected value (expectation, mean) of X is the probability-weighted average of its values. Think of it as the long-run average of many independent observations of X.

E(X)=\mu_X=\sum_{x\in D}x\,p(x)
Worked example

Two coin flips

  1. E(X) = 0(1/4) + 1(1/2) + 2(1/4) = 0 + 1/2 + 1/2 = 1.
  2. On average we expect 1 head in 2 flips of a fair coin.
Worked example

Air-conditioning units ordered

x012345
P(X = x)0.050.150.270.330.130.07
  1. Multiply each value by its probability: 0, 0.15, 0.54, 0.99, 0.52, 0.35.
  2. Add: E(X) = 2.55 units per week.

6. The expected value of a function of X

For any function h(X), weight the values h(x) by the same probabilities. For a linear function the expectation passes straight through.

E[h(X)]=\sum_{x\in D}h(x)\,p(x) E(aX+b)=aE(X)+b

Proof of the linear rule. E(aX+b)=\sum(ax+b)p(x)=a\sum x\,p(x)+b\sum p(x)=aE(X)+b(1).

Worked example

Profit on laptops

A shop buys 3 laptops at $500 each and sells them at $1000 each; the manufacturer buys back unsold laptops at $100 each. X = number sold has PMF p(0) = 0.4, p(1) = 0.1, p(2) = 0.2, p(3) = 0.3, and the profit is h(X) = 1000X + 100(3 − X) − 1500.

  1. Simplify: h(X) = 1000X + 300 − 100X − 1500 = 900X − 1200.
  2. E(X) = 0(0.4) + 1(0.1) + 2(0.2) + 3(0.3) = 1.4.
  3. E[h(X)] = 900(1.4) − 1200 = 1260 − 1200 = $60.
  4. On average the shop expects $60 profit per cycle of buying 3 laptops.
Watch out. In general E[h(X)] ≠ h(E(X)). The shortcut E(aX + b) = aE(X) + b works because h is linear; for h(X)=X^2, compute \sum x^2p(x).

7. Variance and standard deviation

The variance of X is the expected squared distance from the mean; the standard deviation is its square root, in the units of X. The shortcut identity is usually faster by hand.

\text{Var}(X)=\sigma_X^2=\sum_{x\in D}(x-\mu_X)^2p(x) \text{Var}(X)=E(X^2)-[E(X)]^2 \sigma_X=\sqrt{\sigma_X^2}
\text{Var}(aX+b)=a^2\sigma_X^2 \sigma_{aX+b}=|a|\,\sigma_X

For any function h(X), \text{Var}[h(X)]=\sum (h(x)-\mu_{h(X)})^2p(x).

Worked example

Variance of AC units

  1. E(X^2)=0(0.05)+1(0.15)+4(0.27)+9(0.33)+16(0.13)+25(0.07)=8.03.
  2. \text{Var}(X)=8.03-2.55^2=8.03-6.5025=1.5275.
  3. \sigma_X=\sqrt{1.5275}=1.2359 units.
Worked example

Spread of the laptop profit

  1. E(X^2)=0+0.1+4(0.2)+9(0.3)=3.6, so \text{Var}(X)=3.6-1.4^2=1.64.
  2. Profit h(X) = 900X − 1200: \text{Var}=900^2(1.64)=1{,}328{,}400 and \sigma=900\sqrt{1.64}=\$1152.56.
  3. The −1200 shifts every profit equally and does not change the spread.
Red-pencil reminder. Square the multiplier for the variance (a^2), not for the SD (|a|). The added constant b never affects spread.

8. The binomial distribution

Use the binomial model when (1) there is a fixed number n of trials, (2) each trial is a success (S) or a failure (F), (3) the trials are independent, and (4) P(S) = p is the same on every trial. Then X = number of successes in n trials, and we write X\sim\text{Bin}(n,p). The binomial coefficient counts the ways to choose which x trials are successes; p^x is the probability of those successes and (1-p)^{n-x} the probability of the remaining failures.

b(x;n,p)=\binom{n}{x}p^x(1-p)^{n-x} x=0,1,\ldots,n \binom{n}{x}=\frac{n!}{x!(n-x)!}
B(x;n,p)=P(X\le x)=\sum_{y=0}^{x}b(y;n,p)
E(X)=np \text{Var}(X)=np(1-p)=npq \sigma_X=\sqrt{npq}

Why: X is the sum of n independent Bernoulli(p) variables, each with mean p and variance p(1 − p). Means add to np; variances add to np(1 − p).

Worked example

Faculty sampling

A university has equal numbers of male and female faculty. Each month one faculty member is chosen at random for a survey (anyone may be chosen again). X = number of women chosen in 30 months.

  1. Independent monthly choices with P(female) = 0.5: X\sim\text{Bin}(30,0.5).
  2. PMF: P(X=x)=\binom{30}{x}(0.5)^{30}, x = 0, 1, …, 30.
  3. E(X) = 30(0.5) = 15 and \sigma_X^2=30(0.5)(0.5)=7.5.
  4. P(X < 11) = P(X ≤ 10) = \sum_{x=0}^{10}\binom{30}{x}(0.5)^{30}\approx 0.0494.
Worked example

Fraudulent transactions

18% of a company’s online transactions are fraudulent. X = number of fraudulent transactions in a random sample of 50, so X\sim\text{Bin}(50,0.18).

  1. Expected number: E(X) = 50(0.18) = 9.
  2. P(2 < X < 8) = P(3 ≤ X ≤ 7) = b(3) + b(4) + b(5) + b(6) + b(7).
  3. For example, b(3)=\binom{50}{3}(0.18)^3(0.82)^{47}=0.0102.
  4. The five terms are 0.0102, 0.0262, 0.0530, 0.0872, 0.1203; their sum is 0.2969.
Rsum(dbinom(3:7, 50, 0.18)); pbinom(7, 50, 0.18) - pbinom(2, 50, 0.18)
Pythonfrom scipy.stats import binom; binom.cdf(7, 50, 0.18) - binom.cdf(2, 50, 0.18)
Watch out. Translate strict inequalities: P(2 < X < 8) starts at 3 and stops at 7. And check the four conditions; sampling without replacement from a small population is not binomial.

9. The hypergeometric distribution

Use the hypergeometric model when sampling without replacement: a population of N items has exactly M successes, and a sample of n is chosen so that every subset of size n is equally likely. X = number of successes in the sample, X\sim\text{Hypergeo}(n,M,N).

h(x;n,M,N)=\frac{\binom{M}{x}\binom{N-M}{n-x}}{\binom{N}{n}} \max(0,n-N+M)\le x\le\min(n,M)
E(X)=n\frac{M}{N} \text{Var}(X)=\frac{N-n}{N-1}\,n\,\frac{M}{N}\left(1-\frac{M}{N}\right)

The finite population correction \frac{N-n}{N-1} reduces the variance because of sampling without replacement; it is close to 1 when n is much smaller than N.

Worked example

Tagged tigers

13 of a population of 39 Bengal tigers were fitted with GPS collars. Later, 5 tigers are captured at random. X = number of tagged tigers among them: N = 39, M = 13, n = 5.

  1. P(X=0)=\binom{13}{0}\binom{26}{5}/\binom{39}{5}=65780/575757=0.1142.
  2. P(X=1)=\binom{13}{1}\binom{26}{4}/\binom{39}{5}=13(14950)/575757=0.3376.
  3. P(X < 2) = 0.1142 + 0.3376 = 0.4518.
  4. E(X) = 5(13/39) = 1.6667 and \text{Var}(X)=\frac{34}{38}(5)\frac13\cdot\frac23=0.9942.
Rphyper(1, m = 13, n = 26, k = 5) (R’s n is the number of failures, N − M)
Pythonfrom scipy.stats import hypergeom; hypergeom.cdf(1, 39, 13, 5) (arguments N, M, n)

10. The negative binomial distribution

Run independent Bernoulli trials with constant success probability p until a fixed number r of successes has been observed. X = number of failures before the rth success, X\sim\text{NB}(r,p).

nb(x;r,p)=\binom{x+r-1}{r-1}p^r(1-p)^x x=0,1,2,\ldots
E(X)=\frac{r(1-p)}{p} \text{Var}(X)=\frac{r(1-p)}{p^2}
Worked example

An urn with replacement

An urn has 17 black and 8 red balls; each ball is replaced after it is drawn. X = number of red balls before the 5th black ball.

  1. Success = black, p = 17/25, r = 5.
  2. E(X)=\frac{5(8/25)}{17/25}=\frac{40}{17}\approx 2.35 red balls.
Worked example

Recruiting six players

An NBA team wants 6 players; each player asked agrees with probability 0.6. Find the probability that exactly 9 players must be asked.

  1. Nine asked means 6 acceptances and 3 rejections, the last one an acceptance: X = 3 with r = 6, p = 0.6.
  2. P(X=3)=\binom{8}{5}(0.6)^6(0.4)^3=56(0.046656)(0.064)=0.1672.
Rdnbinom(3, size = 6, prob = 0.6)
Pythonfrom scipy.stats import nbinom; nbinom.pmf(3, 6, 0.6)
Watch out. In our notes X counts failures, not total trials. If the question asks for the number of trials, it is X + r.

11. The Poisson distribution

The Poisson distribution models counts of events in a fixed interval of time or space when events occur one at a time, independently, at a roughly constant average rate. We write X\sim\text{Poisson}(\mu).

p(x;\mu)=\frac{e^{-\mu}\mu^x}{x!} x=0,1,2,\ldots E(X)=\text{Var}(X)=\mu

Binomial to Poisson. If X\sim\text{Bin}(n,p) with n → ∞, p → 0, and np → μ, then X is approximately Poisson(μ) with \mu=np. Rule of thumb: the approximation is reasonable when n > 50 and np < 5.

Worked example

Defective chips

Each of 200 chips is defective with probability 0.01, independently. Find P(X ≤ 2).

  1. Check: n = 200 > 50 and np = 2 < 5, so use Poisson with μ = 2.
  2. P(X\le 2)=e^{-2}\left(1+2+\frac{2^2}{2!}\right)=0.1353(5)=0.6767.
  3. The exact binomial answer is also 0.6767 to four decimals: the approximation is excellent here.
Rppois(2, 2); pbinom(2, 200, 0.01)
Pythonfrom scipy.stats import poisson, binom; poisson.cdf(2, 2), binom.cdf(2, 200, 0.01)

12. Summary

A discrete random variable is described by its PMF or CDF. Its mean and variance come from probability-weighted sums, and linear changes follow E(aX + b) = aE(X) + b and Var(aX + b) = a²Var(X). Choose the model from the setting: fixed n independent trials (binomial), sampling without replacement (hypergeometric), failures before the rth success (negative binomial), or counts in an interval (Poisson).

E(X)=\sum x\,p(x) \text{Var}(X)=E(X^2)-\mu^2 \text{Bin: }np,\ npq \text{Poisson: }\mu,\ \mu
R and Python for engineers. R: dbinom/pbinom, dhyper/phyper, dnbinom/pnbinom, dpois/ppois. Python (SciPy): binom, hypergeom, nbinom, poisson, each with .pmf and .cdf. Check the parameter order in each; they differ from the notes for the hypergeometric.
