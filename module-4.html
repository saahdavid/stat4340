1. Continuous random variables and the PDF

A random variable X is continuous if its possible values form an interval (or a union of intervals) of the real line. Its support is the set of values where the density is positive: the values X can actually take. Air temperature might take any value in [80, 100] °F; study time any value in [0, 300] minutes.

  • Check that a function is a valid PDF and find a missing constant.
  • Find probabilities from a PDF (by integrating) or from a CDF (by subtracting).
  • Find percentiles and the median from the CDF.
  • Compute E(X), E[h(X)], Var(X), and the SD by integration.
  • Use the uniform, normal (with z and the table), gamma, exponential, and chi-squared models.

A probability density function (PDF) f(x) gives probabilities as areas under its curve.

P(a\le X\le b)=\int_a^b f(x)\,dx
f(x)\ge 0 \text{ for all } x \int_{-\infty}^{\infty}f(x)\,dx=1

For any single value a, P(X=a)=0: probability comes from intervals, not points. So for a continuous X, P(a\le X\le b)=P(a<X<b).

Watch out. f(x) is a density, not a probability. It can be larger than 1 (a narrow, tall curve); only the area under it must equal 1.

2. The CDF

The cumulative distribution function F(x) is the area under the density to the left of x. Where F is differentiable, its derivative is the density.

F(x)=P(X\le x)=\int_{-\infty}^{x}f(y)\,dy F'(x)=f(x)
P(X>a)=1-F(a) P(a\le X\le b)=F(b)-F(a) 0\le F(x)\le 1
Worked example

A density on [0, 1]

Let f(x)=3x^2 for 0 ≤ x ≤ 1 and 0 otherwise.

  1. Valid PDF: f(x) ≥ 0, and \int_0^1 3x^2\,dx=\big[x^3\big]_0^1=1.
  2. CDF: F(x)=\int_0^x 3y^2\,dy=x^3 for 0 ≤ x ≤ 1 (0 below, 1 above).
  3. P(0.5\le X\le 0.8)=F(0.8)-F(0.5)=0.512-0.125=0.387.
Worked example

Finding a constant

Suppose f(x)=cx for 0 ≤ x ≤ 2. Find c.

  1. \int_0^2 cx\,dx=c\big[\tfrac{x^2}{2}\big]_0^2=2c.
  2. Set it equal to 1: c = 1/2.

3. The uniform distribution

X is uniform on [A, B], written X\sim U(A,B), if every value in the interval is equally likely: the density is flat.

f(x;A,B)=\frac{1}{B-A},\ A\le x\le B F(x)=\frac{x-A}{B-A},\ A\le x<B
E(X)=\frac{A+B}{2} \text{Var}(X)=\frac{(B-A)^2}{12}

F(x) = 0 for x < A and 1 for x ≥ B. The mean and variance follow from the integrals in Section 5.

Worked example

Pipeline breaks

A pipeline is 100 miles long and every location is equally likely to break. X = distance (miles) from the origin to the break.

  1. X\sim U(0,100): f(x) = 1/100 for 0 ≤ x ≤ 100, and F(x) = x/100 on that interval.
  2. P(X = 55) = 0: a single point has no area.
  3. P(32 < X < 43) = F(43) − F(32) = 0.43 − 0.32 = 0.11.
Rpunif(43, 0, 100) - punif(32, 0, 100)
Pythonfrom scipy.stats import uniform; uniform.cdf(43, 0, 100) - uniform.cdf(32, 0, 100) (scipy uses loc = A, scale = B − A)

4. Percentiles and the median

For 0 < p < 1, the (100p)th percentile η(p) is the value with area p to its left. The median \tilde\mu is the 50th percentile: half the area lies on each side.

p=F(\eta(p))=\int_{-\infty}^{\eta(p)}f(y)\,dy F(\tilde\mu)=0.5
Worked example

Percentiles of f(x) = 3x²

  1. The CDF is F(x)=x^3.
  2. 80th percentile: \eta^3=0.8, so \eta=0.8^{1/3}=0.9283.
  3. Median: \tilde\mu^3=0.5, so \tilde\mu=0.5^{1/3}=0.7937.
Watch out. Set the CDF equal to p and solve for x. Setting the density f(x) = p does not give a percentile.

5. Expected value and variance

For a continuous random variable, sums become integrals.

E(X)=\mu_X=\int_{-\infty}^{\infty}x\,f(x)\,dx E[h(X)]=\int_{-\infty}^{\infty}h(x)\,f(x)\,dx
\text{Var}(X)=\int_{-\infty}^{\infty}(x-\mu_X)^2f(x)\,dx \text{Var}(X)=E(X^2)-[E(X)]^2 \sigma_X=\sqrt{\text{Var}(X)}
Worked example

Mean and SD of f(x) = 3x²

  1. E(X)=\int_0^1 x\cdot 3x^2\,dx=\big[\tfrac{3x^4}{4}\big]_0^1=0.75.
  2. E(X^2)=\int_0^1 x^2\cdot 3x^2\,dx=\big[\tfrac{3x^5}{5}\big]_0^1=0.6.
  3. \text{Var}(X)=0.6-0.75^2=0.0375, so \sigma_X=\sqrt{0.0375}=0.1936.
  4. The median (0.7937) is above the mean (0.75): the density is skewed left.
Rf <- function(x) 3*x^2; m <- integrate(function(x) x*f(x), 0, 1)$value; integrate(function(x) x^2*f(x), 0, 1)$value - m^2
Pythonfrom scipy.integrate import quad; m = quad(lambda x: x*3*x**2, 0, 1)[0]; quad(lambda x: x**2*3*x**2, 0, 1)[0] - m**2

6. The normal distribution

X has a normal distribution with mean μ and variance σ², written X\sim N(\mu,\sigma^2), if its density is the symmetric, single-peaked bell curve below. Its support is (−∞, ∞). Changing μ shifts the curve; changing σ² changes its spread. About 68%, 95%, and 99.7% of the area lies within 1, 2, and 3 standard deviations of the mean (the 68–95–99.7 rule).

f(x)=\frac{1}{\sqrt{2\pi}\,\sigma}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right) E(X)=\mu \text{Var}(X)=\sigma^2

The normal density has no closed-form antiderivative, so probabilities are computed numerically for the standard normal Z\sim N(0,1), whose CDF is written Φ(z), and every other normal is reduced to Z by standardizing.

z=\frac{x-\mu}{\sigma} Z=\frac{X-\mu}{\sigma}\sim N(0,1)

A z-score counts how many standard deviations x lies from μ; negative means below the mean. Our convention: round z to two decimals, then read the left area Φ(z) from the table.

Worked example

Three-toed sloth weights

Weights are normal with μ = 4 kg and σ² = 0.36, so σ = 0.6.

  1. P(X > 5): z = (5 − 4)/0.6 = 1.6667 ≈ 1.67. The table gives Φ(1.67) = 0.9525, so P(X > 5) = 1 − 0.9525 = 0.0475.
  2. P(3.7 < X < 4.5): z₁ = (3.7 − 4)/0.6 = −0.50 and z₂ = (4.5 − 4)/0.6 = 0.8333 ≈ 0.83.
  3. Φ(0.83) − Φ(−0.50) = 0.7967 − 0.3085 = 0.4882.
  4. Software with unrounded z gives 0.0478 and 0.4891; the small differences come from rounding z.
R1 - pnorm(5, 4, 0.6); pnorm(4.5, 4, 0.6) - pnorm(3.7, 4, 0.6)
Pythonfrom scipy.stats import norm; norm.sf(5, 4, 0.6), norm.cdf(4.5, 4, 0.6) - norm.cdf(3.7, 4, 0.6)

Working backward. To find the value with a given left area p, find the z with Φ(z) closest to p in the body of the table, then unstandardize: x=\mu+z\sigma. For example, the 90th percentile of sloth weight uses z = 1.28: x = 4 + 1.28(0.6) = 4.768 kg.

Red-pencil reminder. The table gives left areas. For “greater than,” subtract from 1; for “between,” subtract two left areas. Use σ, not σ², in the z-score.

7. The gamma function and the gamma distribution

For α > 0 the gamma function is \Gamma(\alpha)=\int_0^\infty x^{\alpha-1}e^{-x}\,dx.

\Gamma(\alpha)=(\alpha-1)\Gamma(\alpha-1) \Gamma(n)=(n-1)! \Gamma(\tfrac12)=\sqrt{\pi}

X has a gamma distribution with shape α and scale β, X\sim G(\alpha,\beta), if its density is the one below. With β = 1 it is the standard gamma. Its CDF is the lower incomplete gamma function: F(x;\alpha,\beta)=F(x/\beta;\alpha), where F(·; α) is the standard gamma CDF.

f(x;\alpha,\beta)=\frac{1}{\beta^\alpha\Gamma(\alpha)}x^{\alpha-1}e^{-x/\beta},\ x\ge 0 E(X)=\alpha\beta \text{Var}(X)=\alpha\beta^2
Worked example

Gamma values

  1. \Gamma(5)=4!=24.
  2. \Gamma(\tfrac52)=\tfrac32\cdot\tfrac12\cdot\Gamma(\tfrac12)=\tfrac34\sqrt{\pi}=1.3293.
  3. If X\sim G(2,3), then E(X) = 2(3) = 6 and Var(X) = 2(3²) = 18, so σ = 4.2426.

8. The exponential distribution and memorylessness

The exponential distribution is the gamma with α = 1 and β = 1/λ. We write X\sim\text{Exp}(\lambda) with rate λ > 0.

f(x)=\lambda e^{-\lambda x},\ x\ge 0 F(x)=1-e^{-\lambda x},\ x\ge 0 E(X)=\frac1\lambda \text{Var}(X)=\frac1{\lambda^2}

Memoryless property. For any s, t ≥ 0, P(X>s+t\mid X>s)=P(X>t). The remaining waiting time does not depend on how long we have already waited: for a component’s lifetime, P(X > 10 | X > 5) = P(X > 5).

Why: P(X>s+t\mid X>s)=\frac{e^{-\lambda(s+t)}}{e^{-\lambda s}}=e^{-\lambda t}=P(X>t).

Worked example

Machine failure

The time (hours) until a machine fails is X\sim\text{Exp}(0.2).

  1. P(X > 8) = e^{-0.2(8)}=e^{-1.6}=0.2019.
  2. P(3 < X < 6) = F(6) − F(3) = e^{-0.6}-e^{-1.2}=0.5488-0.3012=0.2476.
  3. The mean lifetime is 1/0.2 = 5 hours.
R1 - pexp(8, 0.2); pexp(6, 0.2) - pexp(3, 0.2)
Pythonfrom scipy.stats import expon; expon.sf(8, scale=1/0.2), expon.cdf(6, scale=5) - expon.cdf(3, scale=5)

9. The chi-squared distribution

The chi-squared distribution with ν degrees of freedom is the gamma with α = ν/2 and β = 2, written X\sim\chi^2(\nu). It returns in Chapter 7 for intervals for σ².

f(x)=\frac{1}{2^{\nu/2}\Gamma(\nu/2)}x^{\nu/2-1}e^{-x/2},\ x\ge 0 E(X)=\nu \text{Var}(X)=2\nu

10. Summary

A continuous distribution is described by a density whose areas are probabilities. Integrate f for probabilities and moments, set F(x) = p for percentiles, and standardize normal values with z = (x − μ)/σ before using the table.

P(a\le X\le b)=F(b)-F(a) E(X)=\int x f(x)\,dx z=\tfrac{x-\mu}{\sigma} \text{Exp: }P(X>x)=e^{-\lambda x}
R and Python for engineers. R: punif, pnorm/qnorm, pexp, pgamma(x, shape, scale = β), pchisq, and integrate(). Python (SciPy): uniform, norm, expon(scale = 1/λ), gamma(a = α, scale = β), chi2, and scipy.integrate.quad.
